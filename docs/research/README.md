# Research handoff

Use the Sources tab in the Google tracker as the shared source list. Save supporting notes/files in the Research folder linked from the hub.

For trend and job data record: title, original URL, publisher, published date, fetched date, geography, usage terms, and which role/skill claim it supports. Verify that the source can actually be refreshed. A bookmarked link alone does not demonstrate working data ingestion.

For courses record: real title, provider, official URL, skills taught, prerequisites, estimated time, cost, and date checked. Unknown values remain unknown.

For SDGs record: goal/target, the specific role or skill, and a plain-language reason for the connection. Do not add all 17 goals to every record.

Use fictional demo profiles only. Keep assumptions and test fixtures clearly marked. Do not invent citations, market data, courses or results.
