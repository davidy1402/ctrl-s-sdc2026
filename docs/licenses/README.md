The interface loads Manrope and DM Mono through Google Fonts. Original SIL Open Font License notices were retrieved from the Google Fonts source repository on 23 October 2026 MYT:

- [Manrope OFL](Manrope-OFL.txt), source https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
- [DM Mono OFL](DMMono-OFL.txt), source https://github.com/google/fonts/blob/main/ofl/dmmono/OFL.txt

The fonts remain external network resources; a browser may use fallback fonts offline. The font provider receives ordinary network request metadata, not the fictional assessment answers. The team must confirm provenance and permission for the imported Figma-derived design before public release.
