## AI help

Ask for one small output at a time. Give the relevant context and constraints. Review the answer, check facts at their original sources, run code changes when applicable, and explain the result in your own words. ## Definition of done

A task is done when the promised output exists, the result link is in the tracker, the responsible person has checked it, and any requested reviewer has approved it. A draft, upload in progress or successful command is not automatically a completed deliverable.

## Updates

Update your tracker row before sending a WhatsApp progress message. Use: Done / Next / Need help. Put decisions in the meeting note so they remain easy to find.
