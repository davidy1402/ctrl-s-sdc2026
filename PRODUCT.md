# Aiversecity

## Register
Product: a React/Vite career exploration tool. This records the implemented interface, not a team-approved product strategy.

## Users and purpose
The current synthetic demo helps an explorer assess response patterns, inspect one Data Analyst path and practice skills. Mobile home-screen use is explicitly requested by David. No real personal records or CVs.

## Design direction
Preserve the existing A/orbit identity, dark surfaces, lime primary actions and cyan supporting accents. Clear, calm, approachable task UI; avoid demo badges, duplicate instructions, tiny low-contrast text and internal design-gallery content in the main journey. Keep uncertainty and sources discoverable. Respect reduced motion, readable type and accessible touch targets.
